# Спецификация функции: фоновая финализация интервью

**Ветка** `refactor/add-fisrt-containerization`

**Дата** 24 ноября 2026

**Статус** Реализация и автоматические проверки завершены; ручной двухканальный прогон описан в `quickstart.md`

**Запрос** Выделить седьмой сервис, который доводит сохранённое интервью до готового отчёта с помощью Whisper и аналитики.

## Пользовательские сценарии и проверка

### US1 · P1 · Отчёт после закрытия страницы

Интервьюер завершает звонок. Когда система подтвердила, что приняла интервью на обработку, он сохраняет ссылку и закрывает страницу. По той же ссылке позднее доступны записанный звук, транскрипция и XLSX. Оценка использует версию вопросов, закреплённую за этим интервью.

- **Дано** двухканальное интервью с подтверждённым ответом. **Когда** обработка поставлена в очередь и браузер закрыт. **Тогда** итоговая транскрипция и отчёт доступны по прежнему ID без живой сессии.
- **Дано** обработка ещё идёт. **Когда** интервьюер снова открывает ссылку. **Тогда** отдельно видны состояния звонка, записи и отчёта.
- **Дано** после звонка опубликован новый эталон. **Когда** отчёт готовится в фоне. **Тогда** оценка использует исходный эталон.

### US2 · P1 · Восстановление после сбоя

Оператор перезапускает стенд или его часть во время обработки. После восстановления зависимостей задания автоматически возвращаются в работу.

- **Дано** задание уже принято. **Когда** рабочий процесс остановлен во время распознавания и запущен снова. **Тогда** по прежнему ID появляется один итоговый отчёт.
- **Дано** XLSX подготовлен, но подтверждение публикации потерялось. **Когда** шаг повторяется. **Тогда** та же версия файла публикуется один раз и статус становится «готов».
- **Дано** Whisper временно недоступен. **Когда** запись уже сохранена. **Тогда** запись остаётся доступной, обработка повторяется. При исчерпании попыток допускается явно помеченный резерв Vosk, если он пригоден. Иначе видна ошибка обработки.
- **Дано** исходный пакет повреждён или неполон. **Когда** обработчик его проверяет. **Тогда** отчёт не объявляется готовым, исходники сохраняются для диагностики.

### US3 · P2 · Запуск и приёмка на одном компьютере

Разработчик одной командой собирает и запускает полный пилот. Он видит готовность семи сервисов, открывает интерфейс и может повторить сквозную проверку по инструкции.

- **Дано** чистая копия проекта и запущенный Docker Desktop. **Когда** разработчик запускает быстрый старт. **Тогда** скрипт создаёт локальные секреты, собирает образы и проверяет готовность стенда.
- **Дано** существующий пилот с данными. **Когда** разработчик запускает новую версию с прежними настройками. **Тогда** старые интервью доступны по исходным ссылкам.

### Граничные случаи

- Закрытие браузера во время звонка прекращает захват. Для автоматически остановленного сеанса допускается обработка только принятой части, если удалось закрыть и передать согласованный пакет.
- WAV может быть сохранён раньше, чем готов журнал, снимок аналитики или отчёт. Сам по себе статус записи «сохранена» не подтверждает постановку задания.
- Интервью без ответов, тестовое моно, пропущенные и отменённые ответы сохраняют существующую семантику.
- Повторное получение задания и позднее завершение устаревшей попытки не создают второй отчёт.

## Требования

- **FR-001.** Система долговременно фиксирует задание по завершённому интервью, его версию банка и проверенные входы для расчёта.
- **FR-002.** Итоговое распознавание выполняется по сохранённой записи. Аналитика применяет действующие правила формирования отчёта, включая подтверждённые и пропущенные ответы, уточнения и источник текста.
- **FR-003.** Принятое задание переживает перезапуск STT, аналитики и обработчика. Временные ошибки допускают автоматический повтор.
- **FR-004.** Повтор обработки и регистрации оставляет один итоговый набор артефактов по ID. Конфликт данных фиксируется как ошибка.
- **FR-005.** По ссылке на интервью раздельно видны звонок, запись и подготовка отчёта. «Отчёт готов» означает, что подтверждённый файл доступен для скачивания.
- **FR-006.** Существующий архив остаётся читаемым. Для архивов до внедрения задания постановка на обработку автоматически не выполняется.
- **FR-007.** Инструкция и быстрый запуск охватывают семь сервисов, первую загрузку моделей, повторный старт и сквозную проверку.

### Основные сущности

Интервью и версия банка, снимок завершённого интервью, пакет входов, задание финализации, материалы транскрипции и итоговый отчёт.

## Критерии успеха

- **SC-001.** Сквозной прогон двухканального интервью с закрытой вкладкой отдаёт по исходной ссылке WAV, транскрипцию и открываемый XLSX с ожидаемым ответом.
- **SC-002.** После принудительной остановки обработчика во время распознавания и после подготовки XLSX оба сценария заканчиваются одним скачиваемым отчётом на интервью.
- **SC-003.** При недоступных входах или публикации UI показывает ожидание либо ошибку. После восстановления зависимости корректный файл становится доступен без повторного звонка.
- **SC-004.** Одна команда поднимает новый семисервисный стенд. Повторный запуск сохраняет файлы и доступность старых ссылок.

## Допущения

Гарантия восстановления начинается с подтверждённой постановки задания. Восстановление аудио, которое сервер ещё не получил, и продолжение разговора на другом узле остаются за рамками функции. Сохраняются локальный доступ пилота и текущая политика хранения.
