# Решения по совместимости

Пилот использует Linux/amd64 и CPU. В Windows-версии только проверка Microsoft Runtime и путь загрузки DLL специфичны для ОС. Java вызывает C API NeMo-Speech.cpp через JNA. Linux-сборка должна экспортировать потоковые функции диаризации и соответствовать структурам Java.

CAM++ использует JNI sherpa-onnx. Для Linux нужен нативный пакет той же версии, что и Java API. Vosk уже поставляет Linux-библиотеку. Порог CAM++ и настройки диаризации сохраняем для сопоставимости.

Для старта с чистого компьютера выбираем веса в кэшируемом слое образа с проверкой SHA-256. Привязка к каталогу моделей Windows потребовала бы ручной установки. Для PCM и очереди выбираем именованный том, который переживает замену образа.
