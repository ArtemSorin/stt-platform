# План реализации Linux STT

**Ветка** `refactor/add-fisrt-containerization` · **Спецификация** [003](spec.md)

1. Собрать Java 17 JAR и подключить совместимые Linux x86_64 CPU библиотеки NeMo-Speech.cpp и sherpa-onnx. Проверить загрузку через существующие интерфейсы JNA/JNI.
2. Закрепить и проверить контрольные суммы дистрибутивов и трёх моделей. Разнести сетевую загрузку и компиляцию Java по кэшируемым слоям.
3. Настроить адреса Compose, постоянный том рабочего состояния и публикацию интерфейса на loopback. Упростить первоначальную настройку секретов и запуск.
4. Провести контроль на реальной речи, проверить архив при пересоздании STT и повторной отправке. Зафиксировать проверяемые команды, ограничения и фактические результаты.

**Соответствие принципам.** Интерфейсы и схема БД сохраняются. Русская документация, CI, журнал, C4 и отсутствие приватных данных проверяются перед PR.
