# Данные контейнера

Веса доступны процессу для чтения. Том STT объединяет рабочие каталоги PCM, журналов, результатов диаризации и очереди архива. Идентификатор интервью связывает рабочие файлы с существующими записями PostgreSQL и ключами объектов S3. После подтверждения размера, хеша и регистрации действует существующая очистка.

Имеющиеся таблицы, ключи объектов и формат очереди сохраняются. Пересоздание контейнера с тем же томом возобновляет обработку ожидающих файлов.
