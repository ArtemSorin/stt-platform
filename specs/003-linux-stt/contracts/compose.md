# Контракт развёртывания

Сервис Compose `stt-service` предоставляет локальный порт 8080. Интерфейс передаёт два канала PCM16 16 кГц через существующий [STT API](../../../docs/api/stt.openapi.yaml). Внутри сети STT обращается к `analytics:8083` и `object-store:8333`. Обе стороны используют один INTERVIEW_EVENTS_TOKEN. Доступ к рабочим данным нужен UID приложения. Для варианта Windows можно запускать зависимости Compose выборочно.
