# Приёмка стенда

На машине с Docker Compose и Linux-контейнерами выполнить быстрый старт из [README](../../README.md). Открыть http://127.0.0.1:8080/ в браузере.

Подать речь в основной режим с эталоном через `scripts/smoke-archive.py`. Проверить принятие эталона, распознавание системной речи и интервалы диаризации. После остановки объектного хранилища завершить интервью, пересоздать STT, вернуть хранилище и получить запись и отчёт по прежнему ID.
