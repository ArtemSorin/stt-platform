# Журнал экспериментов

Здесь сохраняются самостоятельные записи о проверках, включая неудачные и промежуточные результаты. История кода в Git показывает *что* изменилось; эти записи помогают восстановить *почему* выбрали решение и при каких условиях его проверили.

- [29–30 октября 2026: подготовка звука и разделение каналов](2026-10-29-30-audio.md)

Для следующей проверки укажите проблему и гипотезу, версию кода и моделей, входные данные и оборудование, порядок запуска, наблюдения с единицами измерения, сбои, вывод и остающиеся вопросы. Ссылайтесь на исходные артефакты и PR. Если запись или модель не может храниться в Git, объясните, где она находится и какая часть проверки не воспроизводится из репозитория.
