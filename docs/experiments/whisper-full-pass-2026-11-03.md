# Пропуски в транскрипции и полный проход Whisper — 3 ноября 2026

## Условия и наблюдения

Исследована локальная сессия продолжительностью 298,424 с по `timeline-events.jsonl`, `timeline.json` и двум Markdown-файлам. Входная запись PCM в старом прогоне не сохранялась. В журнале есть 9 решений аналитики и 7 событий `refined`; одно решение отменено, а последний ответ был короче 0,5 с. Переполнения очереди STT и кандидата не зафиксированы.

На ответе №3 Vosk распознал слова с 43,92 до 62,73 с. Слова Whisper для этого ответа начинались с 56,00 с. Прежняя логика пометила все слова Vosk кандидата между началом и концом ответа как заменённые, включая начало, которого не было в результате Whisper. Так в Markdown исчезла часть ответа. Слова разных ролей при пересечении также чередовались по одному.

## Выявленная причина и гипотеза

Подтверждённая причина ограниченного охвата: Whisper вызывался только после `decision` аналитики, с текущим снимком буфера аудио, прошедшего фильтр роли кандидата. Интервалы без решения, поздно подтверждённый звук и конец интервью не имели обязательного второго прохода. Подтверждённая причина потери текста: весь интервал ответа исключался из Vosk даже при частичном результате Whisper.

Для конкретных первых 12 секунд ответа №3 старые журналы не позволяют разделить влияние фильтра роли, состава отправленного PCM и ошибки распознавания модели `small`: сам PCM тогда не записывался. Это остаётся открытым вопросом качества модели. Локальный тест на другом коротком PCM не доказывает полноту этого ответа.

## Изменение и проверка

После остановки STT читает временный исходный системный PCM и отправляет в Whisper каждый финально подтверждённый интервал кандидата кусками до 12 с. Соседние куски получают по 0,5 с контекста; слова контекста учитываются один раз. Для каждого куска записываются границы и число слов. Когда Whisper возвращает пустой или неполный участок, соответствующие слова Vosk сохраняются. Временный PCM удаляется при штатном закрытии сессии. Markdown по пересекающимся ролям теперь формирует отдельные реплики.

Java-тесты проверяют отправку всех кусков длинного участка, абсолютные таймкоды, сохранение раннего Vosk при частичном ответе Whisper и читаемость пересекающихся реплик. Реальный повтор той же старой сессии невозможен без исходного аудио. Следующая проверка — записать новое интервью с включённым Whisper и посмотреть `whisper_postprocess_chunk`, особенно куски с `words=0`, сравнив их с Vosk и фактически сказанным.
