# Интеграционный тест STT, диаризации и аналитики

Этот внутренний тест проверял общий аудиопоток из браузера: Vosk распознавал слова, Nemotron/CAM++ определяли говорящих, аналитика оценивала ответы и выдавала подсказки, а Whisper асинхронно уточнял завершённые ответы. Тест относится к этапу до разделения микрофона и системного звука на независимые каналы.

## Результат

| Показатель | Значение |
|---|---:|
| Сегменты диаризации | 37: кандидат 24, интервьюер 10, неопределённые 3 |
| Итоговые слова Vosk | 348 |
| Задержка диаризации, медиана / p95 / максимум | 2,26 / 2,84 / 3,00 с |
| Предварительная подсказка от конца ответа, медиана / p95 / максимум | 2,21 / 5,35 / 7,31 с |
| Решение от конца ответа, медиана / p95 / максимум | 4,46 / 10,27 / 13,01 с |
| Асинхронные уточнения Whisper | 9; медиана после решения 9,22 с, p95 17,86 с |
| Вопросы и оценка | 6 вопросов; 5,85/10 |

Переполнения очереди кандидата не было. После прежних переполнений её ёмкость увеличили с 64 до 512 элементов. Целевое значение p95 предварительной подсказки — не более 3 с — в этом тесте не достигнуто. Результат направил дальнейшую работу на ускорение подсказок и сокращение числа реплик с неопределённой ролью.
