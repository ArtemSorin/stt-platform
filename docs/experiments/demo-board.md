# Демо 20 октября: интеграционный прогон

Источник — экспорт доски `Ai Referent.holst`. На доске этот прогон назван тестом интеграции STT (Vosk + Whisper) и диаризации. В тракте общий аудиопоток из браузера поступал в распознавание и определение говорящих; слова сопоставлялись с интервалами ролей, а завершённый ответ мог асинхронно уточняться Whisper. Это прототип до разделения аудиоканалов.

## Результат, записанный на доске

| Показатель | Значение |
|---|---:|
| Сегменты диаризации | 37: кандидат 24, интервьюер 10, неопределённые 3 |
| Итоговые слова Vosk | 348 |
| Задержка диаризации, медиана / p95 / максимум | 2,26 / 2,84 / 3,00 с |
| Предварительная подсказка от конца ответа, медиана / p95 / максимум | 2,21 / 5,35 / 7,31 с |
| Решение от конца ответа, медиана / p95 / максимум | 4,46 / 10,27 / 13,01 с |
| Асинхронные уточнения Whisper | 9; медиана после решения 9,22 с, p95 17,86 с |
| Вопросы и оценка | 6 вопросов; 5,85/10 |

Переполнения очереди кандидата в записи доски не отмечены; до увеличения ёмкости прежняя очередь на 64 элемента переполнялась. Для текущего прогона объём очереди был 512. Цель p95 предварительной подсказки не более 3 с на этом прогоне не достигнута.

Это показатели с доски, без отдельного воспроизводимого набора прогона в `stt-platform`. Они не сопоставимы напрямую с [другим демо](demo-archive.md): записи и условия не подтверждены как одинаковые. Следующими действиями были проверка неопределённых ролей и задержки подсказок, а позже — изменение аудиотракта и границ сервисов.
