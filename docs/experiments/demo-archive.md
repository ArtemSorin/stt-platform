# Демо 21 октября: прогон с сохранённым архивом

В экспорт доски `Ai Referent.holst` вложен `demo 21.10.zip`. В нём сохранены `summary.json`, `integration-summary.json`, события и хронология. Этот архив относится к отдельному интеграционному прогону, а не является машинным отчётом [предыдущего демо](demo-board.md).

## Результаты

| Показатель | Значение |
|---|---:|
| Длительность аудио | 273,429 с |
| Сегменты диаризации | 24 |
| Решения аналитики | 10 |
| Переполнения очередей и потерянные блоки | 0 |
| Пик очереди анализа кандидата | 107 из 512 |
| Конец ответа → предварительная подсказка, медиана / p95 | 1,912 / 6,032 с |
| Конец ответа → решение, медиана / p95 | 7,994 / 13,798 с |
| Конец ответа → подтверждённый показ, медиана / p95 | 8,152 / 13,926 с |
| Слова без подтверждённой роли | 78 |

На доске дополнительно указаны шесть основных и четыре уточняющих вопроса, оценка 6,25/10. Это описание результата конкретного прогона, а не подтверждение качества аналитики на независимой выборке. Точность ролей на живой записи этим архивом не измерялась; число слов без подтверждённой роли нельзя напрямую трактовать как процент ошибки диаризации.

Пики очередей были ниже ёмкости, но p95 предварительной подсказки превышал ориентир в 3 с. Сопоставлять числа с предыдущим демо как улучшение или регрессию нельзя без общей записи и одинаковых условий. Для дальнейшей работы выделили вопросы задержки, коротких и неопределённых реплик и воспроизводимого тестового набора.
