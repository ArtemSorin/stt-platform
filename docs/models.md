# Модели и версии

Linux-образ загружает артефакты STT с повторами сетевых запросов, продолжением частичных HTTP-загрузок и проверкой SHA-256. BuildKit хранит проверенные файлы и недокачанные части в отдельном кэше для каждой архитектуры.

В репозитории хранятся идентификаторы моделей и настройки загрузки; веса остаются вне Git. Для изменяемых upstream-моделей ниже отдельно указано, что фактически закреплено в конфигурации и какой снимок был доступен при подготовке этой документации.

### Примечания к версиям

- Основной сценарий использует Vosk, Nemotron и CAM++. Whisper и FRIDA можно отключить; `fake` и `heuristic` — тестовый и резервный backend, а не модели.
- Браузерный `speechSynthesis` для озвучивания вопроса использует голос и реализацию ОС/браузера. Репозиторий не выбирает и не фиксирует TTS-модель.
- Пример конвертации `coriollon/whisper-large-v3-turbo-russian-codeswitch` в `whisper_server.py` не является текущим default. [GPU-эксперимент на GOLOS](experiments/whisper-golos.md) не подтверждает качество модели на интервью.
- При замене весов обновляйте таблицу и подписи диаграммы по источнику модели и SHA-256 локального артефакта. Не переносите upstream revision на локальные веса без проверки совпадения.

Linux-образ поддерживает нативные `amd64` и `arm64`; архитектуру выбирает Docker Engine, Apple Silicon override-файл не требуется. NeMo-Speech.cpp 0.3.0 CPU: x86_64 SHA-256 `255f12b722ab15b2a38a51cf125d56e3fa97058b528f7e895b39d6a473deb06e`, aarch64 `56858eaf50d19b05902c043f65d0057352bdc107ae380c41053bfbddfc204bf1`. sherpa-onnx JNI 1.13.8: x86_64 SHA-256 `30c93b59381113f9c20aedbbf9fc1ad399158f6bc03dddc0f8934a6e28e069ba`, aarch64 `5123d2e48ae1a7ce82ba89ce153906c651bf418a63db2f7dff82265e6d49c104`. Библиотека Vosk Java 0.3.45 не содержит Linux ARM64 native library; для `arm64` устанавливается `libvosk.so` из официального архива Vosk 0.3.45 с SHA-256 `45e95d37755deb07568e79497d7feba8c03aee5a9e071df29961aa023fd94541`. x64 использует библиотеку из JAR. Контрольные суммы проверяются во время сборки. Веса CAM++ получены из зафиксированного снимка bitsydarel/campplus-onnx@e7bec0a1949af42884eb7911a3c01ba8cf8584b8 и совпадают по SHA-256 с Windows.
