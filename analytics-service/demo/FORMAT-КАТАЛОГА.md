# Формат банка вопросов для интервью

Нужно подготовить два текстовых файла в кодировке **UTF-8** с разделителем **табуляция** (TSV); UTF-8 с BOM также поддерживается. Одна строка — один вопрос. Строки, начинающиеся с `#`, считаются комментариями. Первая строка с названиями колонок должна начинаться с `#` либо быть удалена: обычную строку заголовка загрузчик примет за данные.

Готовые примеры: [основные вопросы](catalog-questions.tsv) и [уточнения](catalog-followups.tsv). Используйте их как образец структуры, а не как проверенный справочник.

## 1. Основные вопросы — `questions.tsv`

Ровно 7 колонок в указанном порядке:

| № | Колонка | Требование |
|---|---|---|
| 1 | `questionId` | Постоянный уникальный ID, например `Q001`. После выдачи не менять при перестановке и редактировании строк. |
| 2 | `order` | Уникальный положительный целый номер порядка вопросов, например `1`. |
| 3 | `level` | Один из уровней: `Стажёр`, `Junior`, `Middle`, `Senior`. |
| 4 | `topic` | Тема вопроса, например `Java Core`. |
| 5 | `question` | Формулировка, которую услышит кандидат. |
| 6 | `reference` | Эталонный ответ на основной вопрос: проверяемые факты и пояснение. |
| 7 | `notes` | Заметки для оценки: что обязательно учитывать; может быть пустым. |

Пример (между колонками — табуляция):

```tsv
# questionId	order	level	topic	question	reference	notes
Q001	1	Стажёр	Java Core	Что такое JVM?	JVM исполняет байткод Java.	Проверить понимание роли виртуальной машины.
```

## 2. Уточняющие вопросы — `followups.tsv`

Ровно 5 колонок:

| № | Колонка | Требование |
|---|---|---|
| 1 | `followUpId` | Постоянный уникальный ID уточнения, например `Q001-F01`; не должен совпадать с ID основного вопроса. |
| 2 | `questionId` | ID существующего основного вопроса из первой таблицы. |
| 3 | `question` | Фактическая формулировка, которую можно задать кандидату. |
| 4 | `reference` | Самостоятельный эталон именно для этого уточнения, содержащий проверяемые факты. |
| 5 | `notes` | Заметки и критерии для оценки уточнения; может быть пустым. |

```tsv
# followUpId	questionId	question	reference	notes
Q001-F01	Q001	Что делает компилятор javac?	Компилирует исходный код Java в байткод файлов class.	Ожидается указание результата компиляции.
Q001-F02	Q001	Какую роль играет JIT?	Компилирует часто исполняемые участки байткода в машинный код во время выполнения.	Проверить отличие от предварительной компиляции.
```

Порядок строк уточнений определяет их порядок в банке; система выбирает из них подходящее по ходу интервью. Незаданные уточнения не должны считаться пропущенными.

## Правила подготовки

- Не вставляйте внутри полей символы табуляции или переносы строк: они нарушат разбор TSV. Текст в каждой ячейке должен быть однострочным.
- Обязательны все колонки, кроме `notes`. Если `notes` пустая, после предыдущей колонки всё равно нужна завершающая табуляция — чтобы сохранить число колонок.
- У каждого `questionId`, `order` и `followUpId` должна быть уникальность; `questionId` уточнения обязан существовать среди основных вопросов. Уровень должен быть допустимым.
- Эталон уточнения должен отвечать на **само уточнение**, а не копировать без проверки эталон основного вопроса. Если ответ сгенерирован, отметьте его как черновик в `notes` и перед использованием дайте проверить специалисту.
- В старом банке отдельные первые элементы некоторых списков выглядят как указания интервьюеру («Попросить…»). Перед использованием перепишите их как вопросы кандидату либо исключите; не выдавайте такую служебную фразу за готовый вопрос.
- Черновики полного исходного набора для заполнения: [50 основных вопросов](catalog-full-draft-questions.tsv) и [249 уточнений](catalog-full-draft-followups.tsv). Во втором файле эталоны пусты, поэтому текущий загрузчик намеренно отклонит его до заполнения.

## Подключение к экспериментальной версии

В настройках `analytics-service` укажите оба файла через `interview.questions-path` и `interview.followups-path`; пути могут быть абсолютными. Примеры настроек находятся в `analytics-service/src/main/resources/application.yml`. Без внешних путей загружаются `interview/team-questions.tsv` и `interview/team-followups.tsv`, полученные 16 ноября. Эталоны уточнений в них помечены авторами как черновики для проверки специалистом. Анализ окончательных ответов выполняется после интервью.
